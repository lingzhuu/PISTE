# DLPFC 151673：脑相关通路与基础过程参照

20 条脑相关通路＋10 条基础过程参照。3,639 个 spots；3,611 个有层标签，28 个无标签 spots 不进入区域检验。Layer 1–6、WM 分别与其余已标注 spots 比较，共 210 组。基础过程参照不保证没有区域差异。

STpathway、GSVA 使用原切片全部 18,004 个合格基因的 SCTransform Pearson residuals；GSDensity 使用 raw counts 经作者函数归一化后的原生 MCA，换通路集不需要重做 SCT/MCA。

每层保留以下条件的并集：ST dCor 最小的前 5 条，或 GSVA 普通置换 BH q < 0.05，或空间随机化 BH q < 0.05。ST 前 5 是排名规则，不是显著性检验。各类 p 值分别在全部 210 组中作 BH 校正。

- ST dCor：越小表示区域表达模式越不同；没有方向性。
- GSD target% / rest%：区域内 PAL 高活性 spots 比例；p 为高低活性与区域的双侧卡方检验（Yates 校正），未校正空间自相关。
- GSVA Δ：target 与 rest 的分数中位数之差。普通及空间 p 都以均值差作统计量，单侧检验 target > rest，各 1,999 次，最小 p=0.0005。
- 空间检验采用六邻接 Visium 图上的 Moran 谱随机化，保持该图的 Moran I，不保证完整变异函数或分数边际分布不变。
